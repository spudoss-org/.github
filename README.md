# .github

Organization-wide defaults for **spudoss-org**. GitHub applies the files in this repo to every repo in the org that does not define its own.

| Path | Effect |
| --- | --- |
| `profile/README.md` | Public org profile page |
| `ISSUE_TEMPLATE/` | Default issue forms (agent-ready specs) |
| `PULL_REQUEST_TEMPLATE.md` | Default PR description |
| `CONTRIBUTING.md`, `SECURITY.md` | Default community health files |
| `workflow-templates/` | "New workflow" starters that call [shared-workflows](https://github.com/spudoss-org/shared-workflows) |

> This repo must be **public** for default community health files to apply to other repos. It holds no secrets or internal standards; those live in [platform-standards](https://github.com/spudoss-org/platform-standards).

Agents working here: read [AGENTS.md](AGENTS.md).
